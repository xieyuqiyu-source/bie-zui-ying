# 后端部署说明

## 环境要求

- Node.js 20+
- npm

## 本地运行

```bash
cd server
npm install
npm run dev
```

默认监听：

```text
0.0.0.0:8787
```

健康检查：

```text
GET /health
```

## 生产构建

```bash
cd server
npm install
npm run build
npm run start
```

## 环境变量

复制 `.env.example` 为 `.env`，并按实际情况填写：

```text
PORT=8787
HOST=0.0.0.0
NODE_ENV=production
WECHAT_APP_ID=
WECHAT_APP_SECRET=
```

`WECHAT_APP_SECRET` 只放在服务器环境变量或本地 `.env` 文件里，不要写进小程序前端，也不要提交到公开仓库。

## 部署注意

- 小程序正式环境必须使用 HTTPS 域名。
- 域名需要配置到微信小程序后台的 request 合法域名。
- WebSocket 域名需要配置到 socket 合法域名。
- 当前版本数据保存在内存里，服务重启会丢失。
- 正式上线前需要接数据库和 Redis。

## 建议生产架构

```text
微信小程序
  |
HTTPS / WSS
  |
Nginx
  |
Node.js API 服务
  |
PostgreSQL / MySQL + Redis
```
